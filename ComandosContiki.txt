4. CARGAR EL FIRMWARE EN LA PLACA: DFU POR USB
===============================================================================

# PASO PREVIO (MANUAL): conectar la nRF52840 Dongle por USB y ponerla en
# modo DFU con el botón de reset.

# DOCKER: subir la aplicación compilada
make TARGET=nrf52840 BOARD=dongle hello-world.dfu-upload

# PARA OTRA APLICACIÓN, sustituir el nombre del objetivo:
# make TARGET=nrf52840 BOARD=dongle mi-app.dfu-upload

# FLUJO HABITUAL:
#  1) Editar mi-app.c y guardar.
#  2) make TARGET=nrf52840 BOARD=dongle
#  3) Poner la placa en modo DFU.
#  4) make TARGET=nrf52840 BOARD=dongle mi-app.dfu-upload
#  5) Abrir el puerto serie para ver los printf().

===============================================================================
5. VER LA SALIDA SERIE (printf) DE LA PLACA
===============================================================================

# HOST: detectar el puerto creado al conectar la placa
ls /dev/ttyACM* /dev/ttyUSB* 2>/dev/null

# HOST: comando de la diapositiva 13 (si la placa aparece como ttyACM0)
picocom -fh -b 115200 --imap lfcrlf /dev/ttyACM0

# HOST: alternativa sin control de flujo por hardware, si lo anterior falla
picocom -b 115200 --flow n --imap lfcrlf /dev/ttyACM0

# Salir de picocom: Ctrl+A, después Ctrl+X.
# Si el puerto es /dev/ttyACM1, sustituye ttyACM0 por ttyACM1.

# IMPORTANTE SOBRE TU DOCKER:
# El alias actual comparte /dev/bus/usb (útil para DFU), pero NO monta
# necesariamente /dev/ttyACM0 dentro del contenedor.
# Por eso resulta más sencillo ejecutar picocom en Ubuntu (HOST).

===============================================================================
6. DIAGNÓSTICO DE USB, PUERTO SERIE Y PERMISOS
===============================================================================

# HOST: comprobar si Ubuntu detecta la placa USB
lsusb

# HOST: ver los puertos serie disponibles
ls -l /dev/ttyACM* /dev/ttyUSB* 2>/dev/null

# HOST: observar mensajes del kernel al conectar o desconectar la placa
sudo dmesg --follow

# HOST: comprobar a qué grupos pertenece tu usuario
id -nG

# HOST: instalar picocom si todavía no lo tienes
sudo apt update
sudo apt install picocom

# HOST: si aparece "Permission denied" al abrir /dev/ttyACM0,
# comprobar que el puerto pertenece al grupo dialout:
ls -l /dev/ttyACM0

# Si corresponde, añadir tu usuario al grupo dialout (se hace solo una vez):
sudo usermod -aG dialout "$USER"

# Cerrar sesión y volver a iniciarla para aplicar el cambio de grupo.
# Si el puerto está ocupado, cerrar cualquier otro monitor serie abierto.
# Si falla DFU, confirmar que la placa ESTÁ en modo DFU antes de repetir
# el comando .dfu-upload.
